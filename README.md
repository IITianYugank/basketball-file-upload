# Basketball File Upload 🏀🔥

Sometimes I just think about how I can complicate my life. This is the perfect example of it—making a file uploading animation from simple to as complex as it got.

**[Try it Yourself Here]** *https://iitianyugank.github.io/basketball-file-upload/*

### What is this?

This is a file upload page. But instead of a boring "Choose File" button and a loading bar, it's a basketball game.

Because why just upload a PDF when you can literally **shoot it into a hoop**?

You drag your file in, pull back like a slingshot, aim at the net, and release. If you swish it, the file uploads. If you miss... well, there's a solid ground waiting for it.

### Features

* 📂 **Drag & Drop File Upload** (or browse)
* 🏀 **Slingshot Drag-to-Aim** mechanics
* 🎯 **Real-time trajectory prediction dots**
* 📄 The file literally becomes the projectile
* 🏀 **Dynamic rim and interactive net** (it actually stretches and bounces when you score)
* 🧱 **Solid ground physics** (bounce and fade if you miss)
* 🔥 **"SWISH! Upload Successful"** dopamine hit

### Why did I make this?

I was sitting there, thinking about standard file upload components. They are fine. They work. They are... boring.

I saw a vision of a basketball going through a hoop and thought, *"Yeah, that's unnecessarily cool."*

What started as a simple CSS animation turned into calculating parabolic arcs with JavaScript, tracking mouse coordinates for a slingshot effect, building custom trajectory simulation loops, and coding collision detection for a hoop rim.

I could have just used `<input type="file">` and called it a day. But I didn't.

### Tech stack (nothing fancy 😭)

Made with:

* **HTML**
* **CSS** (lots of absolute positioning and keyframes)
* **Vanilla JavaScript** (math, physics simulation, and event listeners)

*(No physics engines were harmed in the making of this file uploader)*

### How to use it

1. Open the page.
2. Drag a file into the dashed drop zone (or click Browse).
3. The file turns into a projectile.
4. Click and hold the projectile.
5. Drag backwards to aim. Watch the trajectory dots.
6. Release to shoot.
7. Don't miss. (Or do, and watch it hit the floor).
